# Honza | osobní web

Ahoj, jsem Honza (Jan Kozák). Vystudoval jsem elektrikáře - silnoproud, dnes pracuji jako údržbář elektrotechnik a mimo to mě baví programování, hry a technologie.

**Web:** https://zikotcz.github.io/about-me/

## O projektu

Tohle je můj osobní web. Je celý v jednom souboru `index.html`, bez frameworků a knihoven, napsaný v HTML, CSS a JavaScriptu.

- úvodní animace a plynulé animace při scrollování
- světlý a tmavý režim
- kontaktní formulář přes Formspree
- funguje na počítači, tabletu i telefonu
